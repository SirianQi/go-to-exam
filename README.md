# go-to-exam 🎓

考试式复习 Claude Code 技能：把"复习"变成"考试"。基于知识库出卷、一问一答、自适应追问摸底、人格化老师讲评、历史考卷与错题集沉淀。

> 来源：两轮真实的 C++ 模拟面试实践（2026-08）——一问一答 + 按答得好坏升降难度的追问 + 实时评估 + 复盘归档，预估分 35~40 → 65~70，效果显著，遂产品化为可复用技能。

## 功能

| # | 能力 | 说明 |
|---|---|---|
| 1 | 考试范围 | **当前项目知识库**（默认）/ 用户指定内容（文件、文本）/ **模型自身知识**，三选一，可按主题过滤 |
| 2 | 评估 | 题目对错 + 分数 + 人格化评语：做得好的给进阶建议，做得差的给补法（补什么/用什么资料/什么顺序） |
| 3 | 历史沉淀 | 考生项目根目录 `examine_history/`：历史考卷 + **累积错题集**（错题下次自动变形复现，连续答对 3 次移除） |
| 4 | 老师人格 | 5 种预置 + 自定义；人格只改语气，**不改判分准确性** |
| 5 | 考试模式 | ① **传统型**：出题→作答，不追问 ② **摸底型**（默认）：每题 1~2 轮自适应追问——答得好问更深，答得差问更浅 |
| 6 | 评估模式 | ① **传统型**：结束后统一评估 ② **实时型**（默认）：每题小评 + 结束总评 |

## 安装

```bash
# 方式一：clone 到个人技能目录
git clone <本仓库地址> ~/.claude/skills/go-to-exam

# 方式二：本地仓库软链（更新随 git pull 即时生效）
ln -s /path/to/go-to-exam ~/.claude/skills/go-to-exam
```

重启 Claude Code 会话后生效。

## 用法示例

```text
/go-to-exam                                          # 全默认：当前项目 + 鼓励型良师 + 摸底型 + 实时型
/go-to-exam 范围=C++并发 人格=strict 模式=2 评估=1 题数=8
/go-to-exam 模型知识:TCP拥塞控制 人格=sarcastic
/go-to-exam ~/notes/operating_system.md 人格=free_range 模式=1 评估=1
/go-to-exam 人格=放养                                 # 支持中文名：鼓励/严厉/放养/阴阳怪气/浑水摸鱼
/go-to-exam 人格=我的毒舌前辈 "你要是答错了就疯狂嘲笑我但教我要认真"   # 口述设定 → 生成自定义人格
```

## 参数

| 参数 | 取值 | 默认 |
|---|---|---|
| 范围 | 主题词 / 文件路径 / `模型知识:主题` | 当前项目知识库 |
| 人格 | encouraging / strict / free_range / sarcastic / slacker / 自定义 | encouraging |
| 模式 | 1 = 传统型；2 = 摸底型 | 2 |
| 评估 | 1 = 传统型；2 = 实时型 | 2 |
| 题数 | 4~10 | 6 |
| 难度 | 简单 / 中等 / 困难 | 中等 |

## 老师人格

| 文件 | 人格 | 一句话 |
|---|---|---|
| encouraging.md | 鼓励型良师（默认） | 先肯定再指正，错误说成机会 |
| strict.md | 严厉型良师 | 惜字如金，答错当场纠，分数从严 |
| free_range.md | 放养型良师 | 只给方向不给答案，逼你自学 |
| sarcastic.md | 阴阳怪气型良师 | 毒舌但句句夹干货 |
| slacker.md | 浑水摸鱼型差师 | 口头摆烂，档案严谨 |

**自定义人格**：复制 `teachers_characters/_custom_template.md` 为 `teachers_characters/<英文名>.md` 填写即可；或考试时口述人设，技能现场生成。

## 目录结构

```text
go-to-exam/
├── SKILL.md                     # 技能主文件（流程、判分、归档规则）
├── README.md
└── teachers_characters/
    ├── encouraging.md           # 鼓励型良师（默认）
    ├── strict.md                # 严厉型良师
    ├── free_range.md            # 放养型良师
    ├── sarcastic.md             # 阴阳怪气型良师
    ├── slacker.md               # 浑水摸鱼型差师
    └── _custom_template.md      # 自定义人格模板
```

考试记录不落在本仓库，而是落在**考生当前项目**的 `examine_history/` 下：

```text
<你的项目>/
└── examine_history/
    ├── exam_20260911_01_cpp并发.md   # 历史考卷（逐题作答 + 判分 + 评语 + 总评）
    └── wrong_questions.md            # 累积错题集（我的错误 / 正确要点 / 复现次数）
```

## 设计原则

1. **人格与事实分离**：人格管语气，判分管事实——任何人格下，分数、正确答案、归档都准确完整
2. **错题驱动**：错题集是核心资产；下次考试变形复现（换角度/换数字防背题），连续答对 3 次移除
3. **评估可执行**：建议必须具体——补什么、用什么资料、按什么顺序，拒绝"多练练"式空话
4. **摸底自适应**：追问方向随答案质量升降，答好加深一层，答差拆到最小步
